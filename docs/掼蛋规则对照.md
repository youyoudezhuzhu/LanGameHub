# 掼蛋规则对照：本地玩法 vs 局域网游戏合集

对照对象是 [youyoudezhuzhu/guandan-android-server](https://github.com/youyoudezhuzhu/guandan-android-server)
（v1.6.7）。那个仓库在 [Hanazar-Games/Guandan-Webgame](https://github.com/Hanazar-Games/Guandan-Webgame)
基础上做过几次**规则修正**，目标就是贴合本地打法。本文逐条核对
LAN Game Hub 里 `guandan` 玩法（`packages/engine/src/games/guandan/`）是否与之一致。

## 结论

**主要玩法一致，有 1 处规则差异，另有 1 处交互差异。**

| # | 规则 | 本地仓库 | 合集当前 | 结论 |
| --- | --- | --- | --- | --- |
| 1 | 逆时针出牌 | `(seat+3)%4` | 座位按 `(seat+1)%4` 编号、UI 上左家 = seat+3 | ✅ 几何一致 |
| 2 | 进贡取最大牌、含大小王 | `eligible = 非红桃级牌`，取 `rankValue` 最大 | `tributeCard()` 取 `gdValue` 最大，排除万能牌 | ✅ |
| 3 | 还贡须 ≤10 | `naturalValue <= 10` | `rank <= 10` | ✅ |
| 4 | 抗贡：进贡方合计两张大王 | 只统计进贡方 | `payers` 合计 `BIG_JOKER >= 2` | ✅ |
| 5 | 抗贡后由头游先出 | `dealer = head` | `turn = order[0]` | ✅ |
| 6 | 单下进贡后由**末游**先出 | `dealer = last` | `turn = pays[0].from`（= 末游） | ✅ |
| 7 | 双下先出：贡牌大者先出 | `dealer = 大贡者` | `turn = pays[0].from`（大贡给头游，故 = 大贡者） | ✅ |
| 8 | 红桃级牌是万能牌 | ✅ | ✅ | ✅ |
| 9 | 级牌 > A、< 小王 | ✅ | ✅ | ✅ |
| 10 | 牌型：单/对/三/三带二/顺子/三连对/钢板 | ✅ | ✅ | ✅ |
| 11 | **非炸弹最多 6 张（无「木板」）** | 已删除木板牌型 | 无木板 | ✅ |
| 12 | 炸弹：张数越多越大 | `n*100+value` | `size` 优先 | ✅ |
| 13 | 同花顺介于 5 炸与 6 炸 | `550+value` | `5.5` | ✅ |

| 19 | 还贡交互 | 玩家手动选牌 | 自动选最小 | ⚠️ 差异 |

## 需要修正的地方

### 差异 1（建议修）：还贡允许了红桃级牌

本地仓库（`script.js` 的 `pickRepay`）：

```js
const repayable = state.hands[seat].filter(c =>
  !c.joker && !(c.suit === "♥" && c.rank === state.level) && naturalValue(c.rank) <= 10
);
```

合集当前（`packages/engine/src/games/guandan/index.ts`）：

```ts
function canReturn(card: Card): boolean {
  return card.suit !== 'J' && card.rank <= 10;
}
```

级牌在 2~10 之间时（例如打 7），**红桃 7 是万能牌**，却满足 `rank <= 10`，
会被允许当作还贡牌还出去。本地仓库明确把它排除了。这会让打 2~10 的局里
收贡方有机会把万能牌还掉，和本地打法不符。

**修法**：把万能牌也排除。

```ts
function canReturn(card: Card, level: number): boolean {
  return card.suit !== 'J' && card.rank <= 10 && !isWild(card, level);
}
```

对应 `validate` 里的两处判断也要带上 `state.level`。

### 差异 2（可选）：还贡自动化程度

本地仓库如果还贡方是真人玩家，会弹交互让玩家**自己挑**一张还；
AI 才自动选最小。合集目前一律由玩家手动选（`returns` 阶段需要玩家出牌动作），
这一点其实比本地仓库更接近"真人自己选"，属于可接受的实现差异，
只是本地仓库在 AI 位上是自动的。

## 已确认一致的重点

- **出牌方向**：本地仓库特意从顺时针改成了逆时针（`(next+3)%4`）。
  合集引擎按 `(seat+1)%4` 轮转，而界面把左家映射成 `(me+3)%4`，
  两者在几何上是同一个方向——你的**右手边先出**。
- **去掉「木板」**：本地仓库在 `3edc11e` 明确删除了 9 张三连三张的牌型
  （因为本地打法里非炸弹最多 6 张）。合集同样不支持木板，这点是对的。
- **进贡含大小王**：同一个提交把进贡牌从「不含大小王」改成「含大小王」，
  合集取 `gdValue` 最大，大王 17 最大，一致。
