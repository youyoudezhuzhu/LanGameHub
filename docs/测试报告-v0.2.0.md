# LAN Game Hub 0.2.0 验收

默认 APK 含十款 DeskPark 桌游和原创「流光蛇场」。APK SHA‑256 为 `956b0fc39781ee6861065fee4fb9c1c6f7005971a82c667aa2f0405cc3f88af0`。

## 阶段 D · 实时竞技

- 两个独立 Chromium 上下文通过局域网 IPv4 加入同一房间，分别使用了虚拟摇杆与加速多点触控、方向键。相同局次和版本的双端快照一致。刷新客端后恢复原座位。两端均显示同一个 30 秒回合的最终结算并返回统一大厅。
- 横屏及竖屏的 Canvas 覆盖可用视口。实测播放器支持进入和退出网页全屏，并检查右上角排行榜及底部两侧控件的位置。浏览器拒绝全屏或方向锁时可转动手机继续使用网页布局。
- 引擎测试覆盖同时抢同格、碰撞重生、加速能量、限制掉头、拒绝伪造动作、输入不延迟节拍、停止清理和八座位确定性模拟。流光蛇场使用原创画面与规则。指定的 Slithering.io 仍待确认再分发许可。

## 阶段 E · Saltline

指定上游的 WebSocket 中继独立复测 45 项断言。原始游戏和素材的再分发授权仍需确认，默认 APK 未启用该游戏。

## 阶段 F · pvz_perf

- 已实现 APK 构建时内置完整离线模块。主机统一提供入口、脚本、Wasm 和数据包。游玩时每个浏览器运行自己的实例并使用自己的本地存档，不依赖服务器保存关卡。
- 3 项打包测试验证本地安装流程、返回大厅链接、离线清单、缺件、摘要变更及目录越界，另有网关测试验证只有资源已内置时才发布入口。
- 检查了 v4.0.6 的实际网页附件。它是无 `pvz-perf.data` 的 Bilibili 发行包，构建脚本已实测拒绝输入且不写入游戏目录。网盘清单列出了原生完整包和资源备份，仍缺可核实授权的完整离线 Web 包。默认 APK 未包含原版素材，完整关卡和资产级离线验收待可随 APK 使用的资源。双人合作仍处于源码调研阶段。[v4.0.6 发行说明](https://github.com/YuHao2006/pvz_perf/releases/tag/v4.0.6) · [EA 模组政策](https://help.ea.com/en/articles/plants-vs-zombies/mod-policy/)

## 复现

在已启动的桌面服务和两个 Chromium 上下文验证。Android 调试服务可先将 8787 转发到宿主的 TCP 18795，再使用同一协议脚本。

```sh
python3 tests/lan_protocol.py http://<host>:8787 --cycles 3
python3 tests/browser_smoke.py http://<host>:8787 /tmp/hub-ui
python3 tests/snake_browser.py http://<host>:8787 /tmp/hub-snake-ui
node --test tests/pvz-package.test.mjs
```
