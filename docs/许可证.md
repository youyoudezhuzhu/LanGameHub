安装包内的网页许可可通过同一个局域网地址的 `/licenses/` 下各文件名访问，包括 `DeskPark.txt`、`Node.js-Mobile.txt`、`LLVM.txt`、`ZXing.txt` 和 `npm.txt`。

Saltline 按需构建从 [CandGo 中文联机分支](https://github.com/CandGo/3A-online-web/tree/4917695dde734010969cc5f7e665acb4d61e06e7) 读取源码，并随 Web 产物带上分支的 Apache-2.0 声明、Three.js MIT 和字体 OFL 文本。CandGo 的 README 说明原始发布件及其来源适用各自的上游条款。原始游戏主体的再分发授权尚未核实，公开仓库只提供适配和构建代码。

详情见 [上游源码调研](调研与实施边界.md)。仓库不包含 PvZ 原版素材包、Saltline 恢复原件或 GPL Stockfish 二进制。
